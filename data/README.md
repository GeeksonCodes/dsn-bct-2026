# Data Directory

This directory contains all datasets used in the DSN-BCT LLM Agent project.

## Structure

- **raw/**: Original, immutable datasets as downloaded or collected
- **processed/**: Cleaned and processed datasets ready for model training and evaluation

## Usage

Place raw data files in the `raw/` directory. After processing, save the cleaned datasets to `processed/`.
